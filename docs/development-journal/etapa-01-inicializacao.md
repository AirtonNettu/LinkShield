# Etapa 01 — Inicialização do LinkShield

## Objetivo

Preparar a base inicial do repositório LinkShield para o desenvolvimento.

## O que foi feito

- Validado o ambiente GitHub Codespaces.
- Confirmada a raiz do repositório em `/workspaces/LinkShield`.
- Confirmada a branch `main`.
- Confirmada a conexão com `origin/main`.
- Criada a estrutura inicial de diretórios.
- Criado o arquivo `.gitignore`.
- Criado o arquivo inicial `pyproject.toml`.
- Realizado o primeiro commit local do projeto.

## Conceitos aprendidos

- Diferença entre repositório local e remoto.
- Significado de `HEAD`, `main` e `origin/main`.
- Estados de um arquivo no Git: untracked, staged e committed.
- Função do `.gitignore`.
- Finalidade inicial do `pyproject.toml`.
- Uso de Conventional Commits.
